title: Notification Addresses

The Notification Address tool allows notification addresses to be entered. This is used to mask the true email addresses for users or distribution groups that will be receiving emails from the OM Plus system.

<Image src="https://raw.githubusercontent.com/javeed-321/documentationai-portal/main/images/om-plus-dm/destinations/notification-address-list.png" alt="Notification Address List window with name and address entries" width="484" height="491" />

## Notification Address List

Each entry in the Notification Address List pairs a name with an address:

| Field | Description |
| --- | --- |
| Name | The name that identifies the user or distribution group. |
| Address | The email address associated with the name, used to mask the true email address for OM Plus notifications. |

## Managing Addresses

Use the command menu to add or remove notification addresses.

### Add an Address

To add a new address, select `Add Address` from the command menu.

### Delete an Address

To remove an address, select the address, then select `Delete Address` from the command menu.
