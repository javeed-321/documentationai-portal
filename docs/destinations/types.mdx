title: Types

The Types screen is used to define the drivers to be used with different types of printers. For setting a printer type, see Types in the destination configuration screen.

## Fields

| Field | Description |
| --- | --- |
| Type | A one-word description of the device type. |
| Driver | The exact name, precisely as it appears in the driver list on the target Windows server. |
