---
title: Types
description: Map destination types to Windows print drivers.
---

The Types screen is used to define the drivers to be used with different types of printers. For setting a printer type, see Types in the destination configuration screen.

<Image src="https://raw.githubusercontent.com/javeed-321/documentationai-portal/main/images/om-plus-dm/destinations/destination-types.png" alt="Destination Types window mapping type names to Windows print drivers" width="484" height="366" />

## Fields

| Field | Description |
| --- | --- |
| Type | A one-word description of the device type. |
| Driver | The exact name, precisely as it appears in the driver list on the target Windows server. |
