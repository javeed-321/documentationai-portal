---
title: Dynamic Class Maintenance
description: Define dynamic destination classes that a security group can change.
---

Dynamic destination classes function the same as standard classes, with the major exception being that users in the [security group](/docs/security/creating-security-groups) assigned to the dynamic class can change destinations in the class. In addition, unlike a standard class a dynamic class can belong to only one security group. To access this component, from the OM Plus Control Panel, double-click Dynamic Class Maintenance, and then the Dynamic Class Maintenance screen appears.
