---
title: Registration Status
description: Review licensed OM Plus products, their status, queues, and expiration.
---

From the OM Plus Administration, click Registration Status, and then the following System Registration Status screen appears.

<Image src="https://blob-cdn.documentation.ai/org-852a81c4-9351-4db1-9f23-cefe8e32d308/doc-fa73ad80-2a40-40e1-98c5-3d2641c178de/1782900148702-cgx1nqv1l6e-registration-status.png?fm=auto&auto=compress%2Cformat" alt="System Registration Status window listing licensed products and queues" width="552" height="332" />

The screen lists each licensed product along with its registration details:

| Field | Description |
| --- | --- |
| Product | The name of the licensed OM Plus product (for example, OM Plus DM, Archive, Web Interface, Report Distribution, BC-XOM(SAP), Report Bundler, Context Delivery, My Print Delivery, i-Sat, and Stats Manager). |
| Status | Indicates whether the product is registered. |
| Queues | The number of licensed queues for the product. |
| Expiration | The expiration date of the registration, if applicable. |

<Callout kind="info">If you are moving an OM Plus installation from one computer to another, contact Plus Technologies Support so they can create a new registration key for you.</Callout>

### Hosts

Allows you to select different hosts.

### TRP

Reports the number of Tamper Resistance Prescriptions queues.
