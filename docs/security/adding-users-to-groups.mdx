---
title: Adding Users to Groups
description: Add local users to an OM Plus security group.
---

Local, remote, and login users can all be added to a security group, but local users must be added first. Once a user is part of the security system, they can only access the destinations assigned to their group and only perform the functions defined in the permissions model applied to those destinations. This page explains how to add local users to a group. For the group and permissions concepts these users build on, see [Creating Security Groups](/docs/security/creating-security-groups).

A user can only be in one security group at a time, but a group can consist of one or many users. OM Plus uses the name entered. In UNIX, the name should match the login user ID on the host on which OM Plus is installed.

To add local users to a group, complete these steps:

<Steps>
  <Step title="Open the Security Maintenance Groups screen" icon="window">
    Navigate to the OM Plus Security Maintenance Groups screen.
  </Step>
  <Step title="Add User" icon="user-plus">
    Click Add User.
  </Step>
  <Step title="Enter a user name" icon="keyboard">
    In the Enter User Name field, enter a new user name. The user appears in the list for this group.
  </Step>
</Steps>

<Callout kind="info">Users cannot be added to the group "guest" as this is the default group for any unresolved users.</Callout>
